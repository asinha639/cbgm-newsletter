# CBGM Newsletter

This is a web-based newsletter for the **Center for Biotechnology and Genomic Medicine (CBGM)** at Augusta University.

🔗 Live site: https://asinha639.github.io/cbgm-newsletter/

---

## Overview

This project presents a modern digital newsletter that includes:

- Chair’s Note  
- Spotlight (students/faculty)  
- Events and seminars  
- Publications and presentations  
- Personal achievements  
- Grant opportunities  
- Photo highlights  
- Committee members  

---

## Files

- `index.html` – Main newsletter page  
- `style.css` – Styling for the site  
- Additional `.html` files – Event/photo pages  
- `images/` – All images used in the newsletter  

---

## How to Update

- Edit `index.html` to update content for each new issue  
- Add or update images inside the `images/` folder  
- Duplicate an existing event/photo page to create new ones  

---

## Notes

- This is a static website (no backend)  
- Hosted using GitHub Pages  
- Designed for quarterly updates
